# Introducción
Prueba técnica para INVERSIVA.
Se ha pedido hacer un CRUD en nodeJs y una aplicación que lo consuma en Flutter o en Angular.

## Tecnologías
Para el backend he utilizado NodeJs y con express, Sequalize como ORM y Mysql como base de datos.
En cuanto al frontend, he decidido utilizar Flutter

## Comunicación resumisa
El frontend hace una petición al servidor haciendo un GET para recibir todos los usuarios.
Cuando queremos actualizar un usuario existen o crear uno nuevo, se hace mediante DTOs.
